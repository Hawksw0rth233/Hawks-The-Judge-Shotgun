# Hawks's The Judge Shotgun

The Judge and Mordida Venenosa for SPT 4.1.6.

## Installation

Extract the release ZIP into your SPT root. Requires WTT CommonLib ^3.0.6 and Lots of Ammo ^2.0.0 for .410 ammunition.

Mordida Venenosa and its exclusive barrel and cylinder are available from Mechanic at loyalty level 4. The default flea rules restrict those items.

## Source

Client and server projects are in their respective directories. Update their assembly references for your local SPT install before building. The asset build scripts also require the local DCC exports and extracted reference data. Binary game assets and personal settings are excluded from this source repository.

MIT applies to original mod code. Third-party assets are excluded from that license.
